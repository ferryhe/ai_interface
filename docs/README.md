# ai_interface Documentation

This directory separates current project-facing docs from archived
implementation records.

## Current Docs

- `project-overview.html` - browser-friendly project introduction and usage guide.
- `contracts/fixtures/` - example module-run contract payloads used as compatibility references.

## Archived Records

- `archive/plans/` - early implementation plans for CLI contracts and database shape.
- `archive/superpowers-plans/` - completed managed PR plans retained as
  implementation records and design references.
- `archive/mockup-sandbox/` - completed UI migration notes moved out of active
  mockup component directories.

For day-to-day setup, skill extension, and verification commands, start with the repository root `README.md` and `project-overview.html`.
