# ai_interface Documentation

This directory separates current project-facing docs from historical implementation plans.

## Current Docs

- `project-overview.html` - browser-friendly project introduction and usage guide.
- `contracts/fixtures/` - example module-run contract payloads used as compatibility references.

## Historical Plans

- `plans/` - early implementation plans for CLI contracts and database shape.
- `superpowers/plans/` - historical managed PR plans. These files are retained as implementation records and design references; they are not the current operating guide.

For day-to-day setup, skill extension, and verification commands, start with the repository root `README.md` and `project-overview.html`.
