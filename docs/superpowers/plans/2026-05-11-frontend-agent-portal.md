# Frontend Agent Portal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a frontstage Agent Portal preview where end users enter with a token, chat with the published Agent, and inspect task steps, data, sources, and final result without seeing admin-only Configure/Publish controls.

**Architecture:** Add a new mockup component beside the admin console so the admin surface and frontstage surface can evolve independently. The Portal uses the same four-module pipeline semantics as the backend console, but renames them into user-facing steps and renders curated static records for V1. No sibling repos are read or changed.

**Tech Stack:** React, TypeScript, lucide-react, Vite mockup sandbox, existing `mockupPreviewPlugin` auto-discovery.


