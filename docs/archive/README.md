# Archived Documentation

This directory keeps completed implementation plans and migration notes as
historical records. These files are useful for understanding why earlier
changes were made, but they are not the current operating guide.

- `plans/` - early CLI contract and database-memory implementation plans.
- `superpowers-plans/` - completed managed PR plans and follow-up records.
- `mockup-sandbox/` - completed UI migration notes from the mockup sandbox.

For current setup, extension, and verification guidance, start with the root
`README.md`, `docs/README.md`, and `docs/project-overview.html`.
