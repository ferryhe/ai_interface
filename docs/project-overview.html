项目是什么

ai_interface 是顶层 Agent OS console。Foreground 承载用户对话和工作流进度，Backstage 承载技能目录、manifest、I/O、 事件、artifact、readiness 和可选 HTML UI 的运维审查。

加技能不改核心代码 默认从 skills/builtin、skills/community 和 skills/custom 加载 YAML manifest。
执行默认安全 CLI、HTTP、MCP 执行都需要显式启用 real mode，并受 allowlist、 timeout、输出上限和脱敏保护约束。
契约自动同步 lib/api-spec/openapi.yaml 是 API 真相源，生成 React client 和 Zod schema。

架构

1用户请求进入 Foreground agent
2Planner 依据 enabled skills 生成计划
3Skill runtime 创建 module runs
4执行器按 manifest 安全调用工具
5Backstage 展示 readiness、事件和产物

运行时保留旧的 moduleId 和 module-run 数据模型，同时在 Agent plan 和 skill metadata 中提升 skillId。这让旧 API 兼容，新技能也能通过 manifest 进入计划和 UI。

DAG 模式： 默认计划是 linear。Planner 可以选择 dag，用 stepId 和 dependsOn 声明依赖。运行时会在创建 module runs 前校验 缺失/重复 stepId、未知依赖和循环依赖。

怎么运行

1. 安装依赖

corepack pnpm install

2. 启动 API server

corepack pnpm --filter @workspace/api-server run dev

3. 启动 Agent OS UI

$env:PORT='8080'
$env:BASE_PATH='/'
$env:VITE_DEFAULT_PREVIEW='ai-os/AgentFirstInterface'
corepack pnpm --dir artifacts/mockup-sandbox run dev

4. 打开界面

浏览器访问 http://localhost:8080。Foreground 用于提交 Agent 请求，Backstage 用于查看技能目录、运行详情和产物。

真实执行开关： 默认不会真实调用外部 CLI、HTTP 或 MCP。需要执行时设置 AI_INTERFACE_TOOL_EXECUTION_MODE=real，并配置对应技能的 env。DAG ready-step 并发默认上限为 8，可用 AI_INTERFACE_DAG_MAX_CONCURRENCY 调整。

怎么扩展技能

  1. 在 skills/community/<skillId>/skill.yaml 创建 reviewed community skill，或在 skills/custom/<skillId>/skill.yaml 创建本地实验 skill。
  2. 描述 project、execution、input/output schema、artifact kinds、UI 和权限。
  3. 运行 corepack pnpm run skill:validate。
  4. 如改了 OpenAPI，运行 corepack pnpm --filter @workspace/api-spec run codegen。
  5. 用 API test 和 typecheck 验证后提交 PR。

普通技能应优先保持 manifest-only。只有需要新的核心 executor、API 契约或 UI 能力时才修改 TypeScript。

怎么验证

corepack pnpm run skill:validate
corepack pnpm --filter @workspace/api-server run test

corepack pnpm --filter @workspace/api-server run build
corepack pnpm --filter @workspace/api-spec run codegen
corepack pnpm run typecheck:libs
corepack pnpm --dir artifacts/mockup-sandbox run typecheck
git diff --check

本项目的 readiness 和执行结果会脱敏：API 只返回 env var 名称、缺失项、 readiness 状态和安全 metadata，不返回密钥、MCP server URL、本地 provider URL、auth token 或原始 header。
